# Cloud Architecture and Design Patterns

Practical research assignment for Distributed Programming.

## Objective

Research and demonstrate cloud architecture patterns
and technologies through simple, working implementations.

## Practical Labs

1. Circuit Breaker Pattern
2. Retry Pattern
3. Timeout Pattern
4. Serverless Computing and Docker Containers
5. API Gateway, Load Balancer and Reverse Proxy
6. Hub-and-Spoke Architecture
7. Lift-and-Shift Migration Strategy
8. Bastion Host

## Deliverables

Each lab must include:

- Solution description
- Architecture diagram, when applicable
- Source code and configuration
- Execution instructions
- Screenshots, logs or test results
